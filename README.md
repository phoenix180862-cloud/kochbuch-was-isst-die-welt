# „Was isst die Welt?“ – das Kochbuch

Kostenloses Kochbuch mit Rezepten aus aller Welt, jedes Schritt für Schritt erklärt – mit Kochmodus, Menü-Baukasten und Einkaufsliste. Läuft im Browser und lässt sich als App installieren.

Ein kostenloses Programm von Thomas Willwacher Fliesenlegermeister e.K. · www.thomas-willwacher.de
